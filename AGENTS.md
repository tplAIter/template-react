# Template author guidance

Preserve the closed native-v1 empty-dependency contract and exact manifest digest. Work only from public MIT material; do not import private implementations, fixtures, histories, credentials or internal origins. Retain LICENSE and CODEOWNERS.

Use the actual core checker and five manifest generator APIs. Keep backend/transport injected, validate unknown data, propagate cancellation and test old-result races. Forms require labels, keyboard access, focused errors and pending state. Use existing approved package pins; no package resolution, artifact installation or execution without its own producer/runtime authorization. Never fabricate bun.lock or enable ambient lifecycle scripts. Generated Bun scripts are ordinary user actions, not native action grants.

Next composition, installed source enrollment, template dependencies and full P12 are separate acceptance boundaries. Preserve exact unmanaged-user edits and marker ownership; refuse duplicate/missing anchors before effects.
